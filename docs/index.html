Abstract

Autoregressive decoding faces challenges when the data are not causally ordered, e.g., contain cross-references or future dependencies. Furthermore, once tokens are generated, they are fixed and cannot be modified or improved, unlike how humans can iteratively refine their thoughts. While diffusion LLMs partially address this issue, they do not naturally lend themselves to inserting or deleting arbitrary numbers of tokens in a pre-generated context. We design AutoIndexer as a generative model with a novel training and decoding mechanism that simulates a Chain of Edits, allowing the model to flexibly modify its prior outputs in hindsight via token insertions, substitutions, and deletions. The model learns to predict marker tokens for opening and closing edits, simultaneously moving a cursor to positions in the existing token sequence, analogous to a text editor. Training sequences are obtained by perturbing ground-truth labels with inverse chained edit operations, and the model learns to edit by undoing those inverses. The perturbation training allows AutoIndexer to be robust to erroneous context and adaptable to editing tasks such as code correction. We demonstrate that our method exhibits post-generation context-editing capabilities that most autoregressive and diffusion models lack without compromising performance on standard LLM benchmarks.

What problem does AutoIndexer solve?

Left-to-right decoders commit to an immutable prefix. Revising earlier text usually means discarding the KV cache and regenerating. AutoIndexer supports generate → revise earlier text → continue in a single append-only stream.

How AutoIndexer works

See Figure 1 for the full framework. Three ideas:

  • Chain-of-Edits decoding — the model emits an edit trajectory τ with [EDIT] and [RETURN] markers.
  • Cursor prediction — a cursor head predicts start cursor and end cursor for each edit.
  • Chain-of-Edits RoPE — display-order reassignment via cursor-relative position; keys use cursor-anchored (key-only) RoPE while queries use standard RoPE.
Generation order — tokens are appended to the stream (cache-friendly).
Display order — reconstructed from the edit trajectory for reading and evaluation.
Training — sample corruptions of ground truth x and supervise the model to emit τ.
